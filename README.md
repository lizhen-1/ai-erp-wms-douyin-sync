# ERP/WMS + 多抖店商品同步首期原型

这个目录包含一个可继续扩展的首期原型，目标是把以下主链路先跑通：

`商品待入库 -> 入库前筛选 -> 价格参数录入 -> 入库审核 -> 生成主 SKU -> 多抖店同步 -> 订单核对 -> 出库发货 -> 状态回传`

当前实现是一个无外部依赖的 Python 原型，适合你和技术团队一起对齐业务规则、对象模型和首期接口边界。

## 目录结构

- `erp_wms/models.py`: 核心对象与状态定义
- `erp_wms/repository.py`: 内存仓储
- `erp_wms/services.py`: 首期业务服务
- `erp_wms/demo.py`: 演示脚本
- `tests/test_workflows.py`: 核心链路测试

## 当前覆盖能力

- 统一主 SKU 管理
- 店铺 SKU 映射与店铺级价格覆盖
- 入库前筛选与入库审核
- 入库通过后自动同步到核心抖店
- 同步失败进入异常任务
- 抖店订单和线下定制订单进入统一订单池
- 规则核对与 AI 辅助建议
- 发货后库存扣减
- 售罄后多店联动下架
- 关键操作审计日志

## 运行方式

```bash
python -m erp_wms.demo
python -m unittest discover -s tests -v
```
